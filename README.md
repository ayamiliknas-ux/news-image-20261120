# news-image-20261120

A Python program (PIL only) that draws a newspaper-style infographic summarising
the world's news of Friday, 20 November 2026, and writes it to `$MAKEFUN_OUTPUT_DIR/entry.png`
(1024x1024, ~150 KB).

Stories covered: Russia's overnight barrage on Ukraine after the Shenzhen
trilateral summit, the ICJ's first-ever state genocide ruling (Myanmar/Rohingya),
the COP31 fossil-fuel-free draft, the EU-UK reset deal, the Iran war (Senate
war-powers vote, $48bn cost), markets (Dow -1,101, Anthropic IPO), Saudi-Houthi
exchanges, Estonia's border closure, and more.
